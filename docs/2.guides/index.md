# Guides

Each page is one task, start to finish. Installation is not among them — the [README](../../README.md) covers it, and a second copy would be the one that goes stale.

- [Send a notification](1.send-a-notification.md) — declare a type, write the notification, send it.
- [Add a channel](2.add-a-channel.md) — wire push, SMS or any third-party channel in through your own enum.
- [Build a settings page](3.build-a-settings-page.md) — render the preference grid and store what a recipient changes.
- [Write a suppression policy](4.write-a-suppression-policy.md) — decide when a channel should stay quiet, or wait.
